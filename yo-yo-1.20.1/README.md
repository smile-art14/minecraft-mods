# 神秘溜溜球 / Shenmi Yo-Yo

适用：Minecraft 1.20.1 + Fabric Loader 0.15.11 + Fabric API 0.92.2+1.20.1。

## 操作

- 左键攻击：近战攻击，使用铁质武器级别基础属性。
- 右键空中/方块：向准星方向掷出溜溜球；命中实体造成 8 点伤害，命中后或达到最大距离后自动回到玩家手边。投掷期间会渲染一条从玩家手部持续连接到溜溜球的绳线。
- 潜行 + 右键实体：近距离勒颈。目标会被绳线拉到攻击者前方并短暂悬空、左右挣扎，持续约 1.2 秒后由服务端进行 95% 致死判定；剩余 5% 造成 6 点伤害，并给予短暂缓慢 III、虚弱 II。勒颈期间会显示“手部→颈部”的绳线与颈部绳环。
- 直接右键另一名玩家：站到目标玩家头顶，客户端保持站立姿态；潜行可下来。
- 疾跑 + 右键另一名玩家：使用原版骑乘关系，以普通坐姿骑到目标玩家身上；潜行可下来。
- `/yoyo`：直接获得一个战斗溜溜球，便于测试。

## 联机行为

投掷伤害、勒颈过程与概率、站立锚点和普通骑乘状态都由服务端执行，不依赖客户端本地判定。客户端仅负责绳线、绳环和站立姿态渲染。玩家之间的伤害仍遵守服务器 PvP/伤害规则。

## 合成配方

```
 S 
IRI
 I 
```

S = 线，I = 铁锭，R = 红色羊毛。

## 构建

本目录复用同级 Fabric 1.20.1 工程的 Gradle Wrapper：

```bash
../fabric-example-mod-1.20.1/gradlew -p . build
```

构建产物位于 `build/libs/`。
