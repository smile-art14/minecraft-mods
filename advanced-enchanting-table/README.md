# Advanced Enchanting Table

适用于 Minecraft 1.20.1 + Fabric Loader 的确定性附魔模组。

## 功能

- 1.0.1 修复多人联机同步：房主与远程玩家现在都通过服务器权威的网络状态执行附魔，多选附魔与等级会在客户端和服务端之间完整同步。
- 放入可附魔物品或书，界面只列出与该物品兼容的非诅咒附魔。
- 可同时勾选多个附魔类型，并分别在各附魔的原版等级范围内调整等级。
- 点击“附魔”后一次性准确应用全部所选结果，不使用原版随机附魔池。
- 所选附魔之间会进行冲突检查，无法组成不符合原版规则的组合。
- 已有附魔会被保留；与已有附魔冲突的选项不会显示。
- 消耗青金石和玩家经验等级。创造模式免消耗。
- 方块内物品会持久保存，破坏方块时自动掉落。
- 安装“神秘法杖”模组后，高级附魔台会显示在“法杖”创造模式物品分页中。

## 配方

`DND / OEO / OOO`：D 为钻石，N 为下界之星，O 为黑曜石，E 为原版附魔台。

## 多人联机

服务端/房主和所有加入的客户端都应安装相同版本的 Mod。1.0.1 起不再依赖客户端本地菜单状态来决定最终附魔结果，服务器会校验当前容器并回传完整附魔选择快照。

## 构建

需要 Java 17：`./gradlew build`。生成文件位于 `build/libs/`。
