# 神秘工坊（Fabric 1.20.1）

基于 Fabric 官方 `fabric-example-mod` 的 Minecraft 1.20.1 示例 Mod。

## 内容

- 神秘水晶：基础合成材料。
- 雷鸣法杖：对最远 10 格内的方块或生物右键召唤闪电，不能隔墙攻击；冷却 1 秒，耐久 128。

雷鸣法杖支持引雷、耐久和经验修补。引雷分为三级：引雷 I、II、III 分别让一次攻击依次产生 3、5、7 道独立计算伤害的雷电，每道间隔 0.2 秒。
- 火焰法杖：右击发射移动速度为原版两倍的烈焰弹，基础命中伤害为 10 点并附加 5 秒灼烧；直接伤害受原版护甲、护盾和相关附魔减免，冷却 1 秒，耐久 128。
- 寒冰法杖：右击发射带有蓝色冰霜粒子拖尾的高速雪球，基础伤害为 5 点；命中给予 5 秒缓慢 II。冻结附魔会额外使目标冻结 2 秒，并在冻结期间为生物身体覆盖半透明冰蓝色。支持与火焰法杖相同的弓、弩及通用耐久附魔。

火焰法杖支持弓与弩的附魔：力量提升直接伤害，冲击提升击退，火矢延长灼烧，快速装填缩短冷却，多重射击发射三枚烈焰弹，穿透允许连续命中多个目标；耐久与经验修补遵循原版规则。无限可以附加，但法杖本身不消耗弹药。
- 神秘方块：亮度 10 的装饰方块。
- **勾回 I**：仅可附魔到三叉戟。投掷三叉戟命中生物后，会高速将目标拉向投掷者面前约 1.8 格处；当前最大拉速约 2.8 格/tick，并延长到最多 16 tick，使被勾回目标能够形成足够高的相对接近速度来触发“冲刺”。
- **冲刺 I**：仅可附魔到盾牌。玩家主手或副手持有该盾牌时，会检测前方约 4.5 格内目标；同时根据上一 tick 的实际距离变化与当前相对运动速度计算接近速度，正常疾跑、敌人迎面冲来以及“勾回”高速拉近均可触发。触发阈值约 0.035 格/tick，触发时造成约 4~10 点伤害并强力击退，带 8 tick 冷却。
- **吞剑 I~III**：仅可附魔到原版剑。把带吞剑的剑放在副手，长按右键后会手动产生类似进食的剑材质碎屑粒子与声音，但剑不会进入原版食物逻辑、不会被消耗。视觉上使用 5 阶段模型裁切，从剑贴图顶部开始逐步隐藏，剑柄区域保持原尺寸；最终只保留原贴图底部 6/16 的剑柄部分。完全收缩后停止使用，再次右键才会弹出恢复完整剑身、把剑重命名为“弹簧刀”，并自动发动一次原版风格横扫。吞剑 I/II/III 的基础收缩时间分别约为 36/28/20 tick；快速装填每级再减少 4 tick，最低 8 tick。横扫之刃不仅提高横扫伤害，还把 KillAura 半径从基础 2.75 格依次扩大到约 4.0/5.25/6.5 格。最近目标承受该副手剑的完整材质攻击力与伤害类附魔，其余目标按原版横扫公式受伤；击退、火焰附加、耐久等也会继续生效。
- `/shenmi_kit`：需要 2 级权限，给予测试套装。

1.0.2 起使用离线绘制的专属像素贴图：参考图风格的雷鸣法杖，以及统一金色晶体色板的水晶和方块。

配方会在玩家获得相关材料时自动解锁：获得紫水晶碎片或萤石粉后解锁神秘水晶；获得神秘水晶后解锁法杖和方块。

创造模式物品栏新增“法杖”标签，使用雷鸣法杖作为图标，并收纳模组物品与自定义附魔书；其中已包含“勾回”“冲刺”以及吞剑 I~III 附魔书。高级附魔台安装后会自动识别这些注册附魔；同时快速装填被扩展为可以附到剑上，用来缩短吞剑时间。

## 1.21.1 修复

- 修复正式发布环境中 `ItemRendererMixin` 因客户端 refmap 选择错误导致的启动崩溃。客户端 Mixin 现在显式使用 `client-mystic-wands-refmap.json`，可将开发环境的 `ItemRenderer.render` 正确映射为 Minecraft 1.20.1 生产环境的 `class_918.method_23179`。

## 构建与运行

需要 Java 17。在 PowerShell 中执行：

```powershell
.\gradlew.bat build
.\gradlew.bat runClient
```

构建后的 Mod 文件位于 `build\libs`，运行游戏还需要 Fabric Loader 和 Fabric API。
