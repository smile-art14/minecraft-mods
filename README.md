# Minecraft Mods

利用 ChatGPT / OpenAI 辅助设计、编程、调试与迭代的一组 Minecraft 小型 Mod、附魔与玩法实验项目。

这个仓库主要记录我在 Minecraft Mod 开发过程中完成的各种想法：从法杖、自定义附魔和高级附魔台，到溜溜球战斗、特殊钓鱼、客户端夜视、三维网格世界，以及 Carpet / GCA 假人行为修复。

> 本仓库只收录 **Minecraft Mod 及相关修复代码**。此前工作目录中的光影包、光影研究资料、录像、构建缓存、反编译文件和第三方测试文件均未上传。

## 1. 神秘工坊

目录：[`fabric-example-mod-1.20.1`](./fabric-example-mod-1.20.1/)

这是目前内容最丰富的综合玩法项目，基于 Fabric 1.20.1 开发。

### 主要内容

- **神秘水晶**：多种自定义物品和方块的基础合成材料。
- **雷鸣法杖**：对目标位置或生物召唤闪电，并支持多级“引雷”效果。
- **火焰法杖**：发射高速烈焰弹，并让力量、冲击、火矢、快速装填、多重射击、穿透等原版附魔参与效果计算。
- **寒冰法杖**：发射带冰霜粒子拖尾的高速雪球，造成伤害、减速和冻结效果。
- **神秘方块**：带亮度的装饰方块。
- **独立创造模式分页**：把法杖、自定义物品和相关附魔书集中在专属标签中。
- **测试命令 `/shenmi_kit`**：快速获取测试装备。

### 自定义附魔

#### 勾回 I

三叉戟命中目标后，把目标高速拉向投掷者，可与其他近战玩法组合。

#### 冲刺 I

用于盾牌。根据玩家与目标之间的实际接近速度判断冲撞，在达到条件时造成伤害和强力击退。

#### 吞剑 I ~ III

用于原版剑。副手持剑并长按右键时，剑的模型会从剑尖开始逐渐“缩入口中”，但不会真正消耗武器；完全缩入后再次右键，剑会弹出并发动一次自动横扫攻击。

该效果还支持：

- 多阶段剑模型变化；
- 快速装填缩短吞剑时间；
- 横扫之刃扩大攻击范围；
- 伤害类附魔、击退、火焰附加、耐久等继续参与计算；
- 联机环境下的服务端伤害判定。

更详细说明见 [神秘工坊 README](./fabric-example-mod-1.20.1/README.md)。

## 2. 高级附魔台

目录：[`advanced-enchanting-table`](./advanced-enchanting-table/)

目标是把原版随机附魔改造成一个更直观、可控的附魔流程。

### 功能

- 放入可附魔物品或书后，只显示与其兼容的非诅咒附魔；
- 可以同时选择多个附魔；
- 可以分别调整每项附魔的等级；
- 自动检查互斥附魔组合；
- 保留物品已有附魔；
- 正常消耗玩家经验等级与青金石；
- 创造模式免消耗；
- 方块实体会保存内部物品；
- 破坏方块时自动掉落内部物品；
- 与神秘工坊同时安装时可加入对应创造模式分页。

多人联机版本使用**服务器权威状态**完成最终附魔，避免远程玩家与房主之间出现菜单状态不同步的问题。

详细说明见 [高级附魔台 README](./advanced-enchanting-table/README.md)。

## 3. 神秘溜溜球

目录：[`yo-yo-1.20.1`](./yo-yo-1.20.1/)

这是一个围绕溜溜球设计的战斗与玩家交互 Mod。

### 攻击方式

- **左键近战**：作为普通近战武器使用；
- **右键投掷**：向准星方向发射溜溜球，命中目标后自动回收，并渲染连接玩家与溜溜球的绳线；
- **潜行 + 右键实体**：触发勒颈玩法，把目标拉到攻击者附近并执行服务端判定。

### 玩家交互

- 直接右键其他玩家：站到目标玩家头顶；
- 疾跑 + 右键其他玩家：使用原版骑乘关系坐到目标玩家身上；
- 潜行：离开当前站立/骑乘状态。

项目还包含：

- 联机环境下的服务端状态同步；
- 绳线与绳环客户端渲染；
- 站立姿态修正；
- 回收路径与障碍处理；
- **溜溜球穿透附魔**。

详细说明见 [神秘溜溜球 README](./yo-yo-1.20.1/README.md)。

## 4. 吸铁石附魔

目录：[`magnet-enchantment-1.20.1`](./magnet-enchantment-1.20.1/)

一个用于头盔的特殊附魔实验。

- 附魔：**吸铁石 / Magnet**；
- 最高等级：I；
- 默认作用半径：8 格；
- 附近正在飞行的弹射物会逐渐改变轨迹并被吸向佩戴者；
- 玩家自己发射的弹射物不会被吸回，避免直接自伤；
- 基于 Minecraft `Projectile` 体系，可覆盖箭、三叉戟、雪球、药水、火球等多种原版弹射物。

详细说明见 [吸铁石 README](./magnet-enchantment-1.20.1/README.md)。

## 5. 海之嫌弃钓鱼

目录：[`sea-disdain-fishing`](./sea-disdain-fishing/)

这是一个把“钓鱼”变成高风险事件的特殊附魔 Mod。

**海之嫌弃**只能附魔在钓鱼竿上：

- 钓鱼速度提升至约原版三倍；
- 不再按正常方式给予普通钓鱼战利品；
- 可能钓出敌对生物；
- 也可能触发末影龙、凋零、监守者、已点燃 TNT、TNT 矿车、瞬间伤害药水、龙息弹等特殊结果。

详细说明见 [海之嫌弃钓鱼 README](./sea-disdain-fishing/README.md)。

## 6. X-Ray 可调夜视

目录：[`x-ray`](./x-ray/)

这里的 X-Ray 并不是传统的矿物透视材质，而是一个**纯客户端可调夜视 Mod**。

### 默认按键

| 按键 | 功能 |
| --- | --- |
| `X` | 开启 / 关闭夜视 |
| `[` | 夜视强度降低 10% |
| `]` | 夜视强度提高 10% |

状态与强度保存在：

```text
config/x-ray.properties
```

当前实现不会向玩家真实药水效果列表写入夜视，而是直接控制本地客户端渲染，并通过客户端 Mixin 向需要查询夜视状态的渲染逻辑提供虚拟结果。因此在多人服务器中，服务端的药水效果同步不会覆盖本地 X-Ray 状态。

该项目只需要 Fabric Loader，服务端无需安装。

详细说明见 [X-Ray README](./x-ray/README.md)。

## 7. Shenmi Grid World

目录：[`grid-world-26.2`](./grid-world-26.2/)

这是一个面向 **Minecraft Java Edition 26.2 + Fabric** 的世界生成实验。

它不会直接替换原版世界生成器，而是在原版 NOISE 地形完成后，把自然地形大面积挖空，只保留稀疏的三维网格骨架，然后继续执行 SURFACE、CARVERS、FEATURES 和结构生成流程。

### 默认网格

```properties
gridSpacing=5
gridThickness=1
```

自然地形方块只有在 X/Y/Z 三个坐标中至少两个命中网格位置时才会保留，从而形成三维线框式世界，而不是简单的平面切片。

项目目标包括：

- 主世界、下界、末地统一网格化；
- 尽量保留原版生物群系；
- 保留村庄、神殿、矿井等后续结构生成；
- 避免每次加载区块时重复挖掘旧区块；
- 允许通过配置文件调整网格间距与厚度。

详细说明见 [Shenmi Grid World README](./grid-world-26.2/README.md)。

## 8. Carpet / GCA 假人修复

目录：[`fake-player-fall-damage-fix`](./fake-player-fall-damage-fix/)

该目录记录 Minecraft 1.21.4 环境下对 Carpet 与 Gugle Carpet Addition（GCA）假人相关问题的分析和补丁源码。

目前处理的问题包括：

- 假人移动时落地处理被错误跳过，导致摔落伤害异常；
- 替换 Carpet 中已经不适合当前版本的递归摔落处理；
- 使用原版方块落地逻辑结算伤害，使干草块、黏液块等特殊行为继续生效；
- 假人死亡后经验未正确清零，重新召唤并再次死亡时可能重复掉落经验；
- GCA 停服保存驻留假人时可能被真实玩家或不驻留假人提前中断；
- 假人驻留和动作恢复相关规则默认状态处理；
- 单人世界退出时玩家列表提前清空，导致驻留假人数据被覆盖的问题。

出于代码与仓库整洁考虑，GitHub 仓库中只保留本项目自己编写的补丁源码和安装说明，**没有上传第三方 Mod JAR、Minecraft 服务端、反编译源码或测试服务器文件**。

## 构建

大部分 Fabric 1.20.1 项目可以在对应目录中使用 Gradle Wrapper：

```powershell
.\gradlew.bat build
```

Linux / macOS：

```bash
./gradlew build
```

通常构建产物位于：

```text
build/libs/
```

具体 Java 版本、Fabric Loader、Fabric API 和特殊构建方式请查看相应子目录中的 README。

> `yo-yo-1.20.1` 当前复用同级 `fabric-example-mod-1.20.1` 的 Gradle Wrapper；`grid-world-26.2` 使用独立的 Minecraft 26.2 / Java 25 构建环境。

## 注意事项

1. 各子项目处于不同开发阶段，部分内容主要用于实验或个人玩法测试。
2. 多人联机使用时，请确保需要服务端支持的 Mod 在服务端与客户端安装兼容版本。
3. X-Ray 为纯客户端项目，不需要服务端安装。
4. 世界生成类 Mod 建议使用新世界测试，避免对重要存档直接操作。
5. 使用补丁类项目之前请备份原 Mod、配置文件和世界存档。
6. 各项目的许可证以对应子目录中的 `LICENSE` 或来源说明为准。
